# Build Checklist

## Fixed Student Journey

Taste test → Scout-like preference questions → live TinyFish discovery, filters and explicit target selection → sourced eligibility → readiness interview → manual timetable → grouped Research/Company roadmap overview and timelines.

The slices below group implementation work; they do not reorder these screens. The taste test is first, never an optional step after discovery.

Build mode: Fast. Verify and commit each slice with brief explanations; pause at the early hands-on checkpoint and final review. Save the code/security learning wrap-up for after the full build.
