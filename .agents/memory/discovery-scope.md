## Scout-like discovery, rebuilt fresh
Learner: “i want scout here but not direct integration”; “scout is very very imp here so i want you to replicate it”.
**Rule:** match Scout's advanced preference-driven TinyFish discovery (plus taste-derived parameters), with filters and explicit student selection. Never substitute a fixed catalog, another search provider or a reduced feature set; never copy Scout code.
**Why:** a fixed-catalog suggestion was once mistaken for agreement and removed the core experience.
**How to apply:** familiar programme names are examples, not the pool. Any deferral is a proposal until the learner accepts it.

## Journey order is settled
Genre taste test on real questions → Scout-like preference questions → discovery/selection → eligibility → readiness → manual timetable → grouped Research/Company roadmaps. Don't reopen it or redesign around it.

## Sources: label, don't drop
Learner wanted “not only on official sources but see others also … for more info of same internships”.
**Rule:** show quote-validated third-party pages as unverified other sources and merge them with the official page of the same internship, but only when cycle/deadline evidence agrees (a missing cycle key is not a wildcard — an archived page must not close a current posting). Every downstream quote keeps its unverified label.
**Why:** dropping evidence for lack of ownership proof made searches look empty; merging across cycles corrupts deadlines.

## AI provider
Learner approved Groq with their own key for the extraction role Scout used OpenAI for. Earlier the learner said Groq must stay free (“i want free”). Later the learner asked to drop Groq for Replit-managed AI “as in scout”; Replit AI Integrations were not offered in this workspace (an org admin can switch them on), so Groq stayed.
**How to apply:** don't assume paid Groq is authorized; if Replit AI Integrations become available and the learner still wants them, the switch is requested.

## Explicit notice before application coding
Learner: “before building let me know like when you start to code.” Announce before scaffolding, dependency installs or app code edits.
