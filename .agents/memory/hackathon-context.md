## Hackathon constraints (verified from rules page, Oct 13 2026)
- Deadline Oct 26 5pm EDT = Oct 27 2:30 AM IST. Judging Oct 27–31; winners ~Nov 5 IST.
- Stage 1 pass/fail: built with Devpost Learn Skill Pack (challengepost/learn-ai-basics); public repo must contain approved scope.md, prd.md, spec.md (skill pack writes them in devpost/). Open-source license required, visible in repo About.
- Must start from an empty folder during submission period. Old ideas OK, old code NOT. Pre-existing work incorporated must be disclosed.
- The learner's earlier Scout project is related work, built inside the submission period but without the skill pack. No direct integration or copied code; rebuild relevant discovery functionality fresh and disclose feature inspiration. Never backfill planning docs onto Scout. **Why:** the learner chose a fresh implementation rather than depending on an organizer's ruling.
- Scout is a separate bounty submission, so the hackathon app must have its own visual identity. Its value here is feature inspiration: preference-driven live TinyFish discovery, filters, student selection and quoted source evidence. A curated program catalog is not an approved substitute.
- Stage 2 equal weights: Design, Potential Impact, Innovation, Presentation. Tie-break order starts with Design.
- Judges don't run code: demo video under 3 min on YouTube/Vimeo is what they actually judge.
- Skill pack rule: agent must not draft/rewrite the user's submission text (spelling/grammar only). Planning interviews are learner-led.
- "Will It Ship" live review Oct 23 12:30 AM IST, using early submissions posted in the Devpost Discord forum.

## Locked concept
Funded-internships-abroad readiness for Indian undergrads applying this cycle.
Journey: taste test on real project descriptions → eligible programs (nationality/year/CGPA/branch) → AI readiness interview → readiness map + one next step fitting exam weeks/free hours.
- Visa-approval odds cut. **Why:** no reliable public data; fabricated probability would fail scrutiny.
- Timetable photo parsing = stretch, decided at Oct 17 checkpoint.
- Cut order if behind: readiness interview becomes self-check first.
**Why this angle:** generic study planners, gamified streak apps, viva coaches, PYQ analyzers and single-JD skill-gap tools all already exist (checked Oct 13); differentiation is heterogeneous requirements (skills + docs + professor outreach), nationality eligibility, and verified levels.
